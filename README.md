# ESP32 eWeLink Matter Bridge

ESP32 / eWeLink LAN / Matter Bridge research and development project.

本 repository 目前處於 bootstrap 階段，architecture、framework、target MCU 與 protocol contract 尚未 freeze。

本專案採 AI-assisted development，並維持 human-in-the-loop transparency：重要方向、範圍與驗證由人類確認，Codex 僅在明確授權的 scope 內協作。
