# ESP32 eWeLink Matter Bridge

ESP32 / eWeLink LAN / Matter Bridge research and development project. The intended direction is local-first control; it does not currently claim device or Matter-controller support.

S2A/S2C authority pins ESP-IDF + esp-matter and separates a constrained ESP32-C3 Wi-Fi profile from an ESP32-S3 high-margin development fallback; S2B added a host-tested portable foundation. Protocol runtime, hardware validation and concrete carrier/product board remain pending.

本專案採 AI-assisted development，並維持 human-in-the-loop transparency：重要方向、範圍與驗證由人類確認，Codex 僅在明確授權的 scope 內協作。
